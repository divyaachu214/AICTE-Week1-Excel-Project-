# AICTE Internship – Week 1 Project

## Excel Data Cleaning and Analysis

### Project Overview
This project is part of my AICTE Internship – Week 1 assignment. The main objective is to clean, organize, and analyze sales data using Microsoft Excel.

### Tools Used
- Microsoft Excel
- GitHub

### Tasks Completed

1. **Data Cleaning**
   - Removed duplicate records.
   - Identified and handled missing values.
   - Cleaned the sales dataset.

2. **Pivot Table Analysis**
   - Created a Region-wise Sales Pivot Table.
   - Created a Category-wise Revenue Pivot Table.

3. **Statistical Analysis**
   - Calculated Mean.
   - Calculated Median.
   - Calculated Mode.

4. **Top 10 Sales**
   - Highlighted the top 10 sales values using Conditional Formatting.

5. **Data Visualization**
   - Created a Category-wise Revenue Bar Chart.

### Project File
`AICTE_Week1_Sales_Project.xlsx`

### Learning Outcomes
- Learned basic data cleaning techniques in Excel.
- Understood how to create and use Pivot Tables.
- Practiced statistical functions.
- Learned Conditional Formatting.
- Created charts to visualize sales data.
- Learned how to upload project work to GitHub.

### Conclusion
This project helped me improve my Excel skills and understand the basics of data cleaning, analysis, and visualization.
